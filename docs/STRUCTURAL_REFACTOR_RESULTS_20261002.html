FigDebate: structural refactor and bounded qualification

2 October 2026 · Working tree updated; no commit or push performed

Outcome: routing, request delivery and configuration defects are fixed. No semantic candidate qualified for promotion. Production retains focused-audit-1 and its existing gate; feedback remains disabled. No new model, reviewer or recovery allowance was added.

Changes in the maintained pipeline

  • Source identity no longer overwrites the selected issue or marks background/invalid-contract work visually resolvable. Unqualified issue tags still receive broad neutral visual coverage; saved traces showed those tags can themselves be wrong. Concrete requested facts take precedence.
  • All question origins use the same capability policy. Caption questions do not silently become pixel questions. Rejected requests do not create unrelated generic questions. Compound visual instructions are rejected, while genuine relational questions retain both participants.
  • Tribunal witnesses receive the existing typed VisualQuestion directly, including source, ID, answer kind and budget. Native calls no longer reconstruct a large wrapper prompt or re-infer a supplied question type. Legacy text adapters remain explicit; missing request headers fail visibly.
  • The compiler preserves the requested source role for semantic verification requests. Visible wording is distinguished from caption interpretation. Initial broad coverage remains because narrower questions based on unqualified tags could suppress decisive text.
  • CLI and direct StagewiseRunner defaults share one resolver. Explicit baseline controls stay baseline; unknown runtime modes fail instead of silently behaving like baseline. The CLI mode list comes from the same registry.
  • The graph-driven early-return plan, generic replacement cascade, unreachable router return and unused critique-quality helper were removed. Language-only hearings remain eligible. Existing source/image provenance, uncertainty, completion safeguards and final acceptance checks are retained.

Arithmetic fidelity cannot repair a faulty semantic translation.
  • 763 automated tests: 762 passed, one pre-existing expected failure in scoring independence, no unexpected failures. Tests cover source roles, rejected dispatch, graph precedence, explicit defaults, uncertainty projection, operand swapping/unit conversion, real gate invariants and existing checkpoint/recovery behavior.
  • The ordinary CLI prepared a one-case local selection without inference. A separate parser check confirmed stagewise / focused-audit-1 / grounded / feedback disabled. The two unsuccessful new candidates are absent from the production CLI registry.
  • git diff --check passed. The initial arbiter was not edited in this turn; pre-existing uncommitted changes were preserved.

What remains unresolved

The stable semantic errors remain: intentions versus actual outcomes, over-literal verification of figurative meaning, and acceptance of claims whose decisive qualifier is unproved. The current gate still depends on fallible model judgments. No dataset-wide accuracy gain is claimed. The reserve cohort was not run because the predeclared pilot promotion condition failed. Full dataset evaluation remains user-controlled. Model replacement/training and a wider decomposition deployment were conditional proposals and were not undertaken.
